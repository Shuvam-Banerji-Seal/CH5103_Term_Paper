# Fonts used by the video scenes

Copied from TeX Live 2026 (`texmf-dist/fonts/opentype`) so the video matches the slides and renders the same on
any machine (ManimGX reads them through `font_paths`).

| font | files | licence |
|---|---|---|
| TeX Gyre Chorus (calligraphic titles) | `texgyrechorus-mediumitalic.otf` | GUST Font License (`GUST-FONT-LICENSE-TeXGyre.txt`) |
| Libertinus Serif / Math (body text, maths) | `LibertinusSerif-*.otf`, `LibertinusMath-Regular.otf` | SIL OFL 1.1 (`OFL-Libertinus.txt`) |
| EB Garamond (labels, small caps) | `EBGaramond-*.otf` | SIL OFL 1.1 (`OFL-EBGaramond.txt`) |
| JetBrains Mono (code) | `JetBrainsMono-*.otf` | SIL OFL 1.1 (`OFL-JetBrainsMono.txt`) |
